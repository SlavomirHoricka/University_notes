# H04 checks and observations

Scope: app shell, catalogue, course/week navigation, provider/health reads, and material selection/storage boundary. No learner evidence is created. Fixtures are fictional and exist only in test modules or browser route interception.

From apps/learning_hub/frontend, run npm run lint, npm run typecheck, npm run test, and npm run build. Tests map H04-A1 to later-week navigation after a failed assessment; H04-A2 to full course identity, explicit scope, and unknown evidence; H04-A4 to local selection, saving, durable storage acceptance, idempotent retry, and navigation preservation.

For browser observations, start the actual selected-checkout loopback backend on port 8765 and Vite on 5173. Run node tests/h04.browser.mjs; H04_BROWSER_ORIGIN and H04_SCREENSHOT_DIR override those observation paths. Playwright's browser path may be supplied with PLAYWRIGHT_BROWSERS_PATH. The script first checks actual scaffold service health and honest missing-feature errors, then intercepts API reads inside a fictional test browser to inspect desktop, narrow, menu, week, empty, error, and upload views. Screenshots are generated outside tracked source and must be opened and inspected before H04-A3 is claimed. Browser assertions also cover overflow, menu Escape, back navigation, retry and absence of JavaScript errors.

The client is a frontend-owned narrow seam under src/api/client/, approved by root. Types remain generated/foundation-owned. Production has no fixture registration or fallback. Upload retries preserve the same request key and original bytes; missing local-session authorization fails before bytes are sent. Selected files stay in memory across app navigation and are not durable until accepted by the backend. Reloading the page loses local selections.

Known integration prerequisites: H03 supplies catalogue reads and generated local-session shapes, H07 supplies durable upload handlers, H05 supplies session start/player actions, and H13 supplies full Agents/account controls. H02 AuthoringRef-only lesson metadata is shown as unknown until the foundation's compatible typed metadata extension is accepted. The QA-owned H00 scaffold smoke selectors need updating for the new overview heading and scoped status locator; this owner does not edit QA e2e paths.
