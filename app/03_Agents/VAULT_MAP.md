# Runtime content boundary

This app source package intentionally has no populated vault inventory. Original course sources, notes, diagrams, curriculum history, ingestion indexes and learner evidence remain in the notes repository.

The legacy workflow-source fork uses fictional course layouts in tests. A future app-owned runtime data directory must be selected explicitly; do not scan the parent/sibling repository or infer readiness from source folders. The website will own uploaded sources and persisted learning state; Markdown is intended as an export format. The storage/owner bridge is pending implementation and review.
